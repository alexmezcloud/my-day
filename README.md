# Мой день

Личное приложение на каждый день: еда, зал, уход за кожей, замеры веса и талии, список покупок.

- Открыть: https://alexmezcloud.github.io/my-day/
- На телефоне: открыть ссылку → «Поделиться» → «На экран Домой» (iPhone) или меню → «Добавить на главный экран» (Android).
- Данные (галочки, замеры) хранятся только в браузере телефона. Раз в месяц: вкладка «Замеры» → «Сохранить копию».

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | всё приложение: план, логика, внешний вид |
| `manifest.webmanifest` | название и иконка для установки на телефон |
| `sw.js` | офлайн-режим: открывается без интернета |
| `icon*.png`, `icon.svg` | иконки |

## Что поменять в плане

В `index.html` в начале скрипта: `DINNER` — ужины по дням, `MEALS` — завтрак/обед/перекус, `WORKOUT` — упражнения, `SHOP` — список покупок, `START` — дата старта программы.
